# trainerVerb_cpp

Консольный тренажёр неправильных глаголов английского языка на C++17. Программа проводит тест на формы V1–V2–V3, проверяет ответы с учётом регистра и пробелов, считает точность и время прохождения, а также сохраняет историю результатов.

## Возможности

- Тесты на 10, 20 или 50 вопросов.
- База глаголов загружается из файла `verbs.txt`.
- Если файл отсутствует или повреждён, используется встроенная база из 20 глаголов.
- Поддержка альтернативных форм, например `learnt/learned`.
- Проверка ответа без учёта регистра и лишних пробелов.
- Подсчёт правильных ответов, процента точности и общего времени.
- Расчёт среднего времени на один вопрос.
- Сохранение результатов в `stats.txt`.
- Просмотр истории результатов из главного меню.

## Структура проекта

```text
.
├── main.cpp       # Точка входа и пользовательское меню
├── Trainer.h      # Объявление класса Trainer
├── Trainer.cpp    # Логика загрузки, теста, результатов и статистики
├── Verb.h         # Объявление класса Verb
├── Verb.cpp       # Хранение глагола и проверка ответов
├── verbs.txt      # Внешняя база неправильных глаголов
└── stats.txt      # История результатов
```

## Формат файла verbs.txt

Каждая строка содержит четыре поля, разделённые символом `|`:

```text
V1|V2|V3|перевод
```

Пример:

```text
go|went|gone|идти
learn|learnt/learned|learnt/learned|учить
```

Строки, начинающиеся с `#`, и пустые строки игнорируются.

## Сборка и запуск

### Linux / macOS

```bash
g++ -std=c++17 main.cpp Trainer.cpp Verb.cpp -o trainer
./trainer
```

### Windows (MinGW)

```bash
g++ -std=c++17 main.cpp Trainer.cpp Verb.cpp -o trainer.exe
trainer.exe
```

## Как пользоваться

1. Запустите программу.
2. Выберите режим теста: 10, 20 или 50 вопросов.
3. Для каждого вопроса введите формы V2 и V3.
4. Программа сразу покажет, верен ли ответ, и при ошибке выведет правильные формы.
5. После теста увидите результат, время и среднее время на вопрос.
6. Результат автоматически добавится в `stats.txt`.

## Архитектура

Проект разделён на две основные сущности:

| Класс | Ответственность |
|---|---|
| `Verb` | Хранит одну запись глагола: V1, V2, V3 и перевод. Отвечает за нормализацию и проверку пользовательского ответа. |
| `Trainer` | Управляет базой глаголов, генерацией вопросов, таймером, подсчётом результата и сохранением статистики. |

`main.cpp` отвечает только за меню и взаимодействие с пользователем, не содержит бизнес-логики теста.
