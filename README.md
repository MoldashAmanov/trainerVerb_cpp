# trainerVerb_cpp
Тренажер неправильных глаголов английского языка

Консольное приложение для тренировки неправильных глаголов английского языка с базой 200 глаголов


- Глаголы загружаются из файла "verbs.txt"
- Есть встроенная база, если из файла не загружается
- Игнорирование пробелов, регистров
- Сохранение истории результатов в текстовый файл
